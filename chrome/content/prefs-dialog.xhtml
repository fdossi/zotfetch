If left blank, ZotFetch uses its built-in contact address. CORE Repository API Key (optional) Free key at core.ac.uk/services/api — raises rate limit to 10,000 req/day and unlocks download URLs. Institutional Access University / Institutional Proxy URL ZotFetch wraps every DOI URL through this address so requests arrive authenticated by your institution’s subscription. Works on-campus, via VPN, or with cookie-authenticated EZproxy sessions. Leave empty if your institution is not supported. Supported URL formats & examples EZproxy — most common in universities https://proxy.uni.edu/login?url= https://eresources.uni.edu/login?qurl= https://proxy.uni.edu/login?qurl={url} (ZotFetch replaces {url} automatically) https://proxy.uni.edu (bare base — ZotFetch appends /login?url=) How to find your proxy URL Search your library website for “off-campus access” or “remote access” The URL usually contains words like proxy, login, or ezproxy Copy the part up to and including ?url= or ?qurl= Enable CAPES Portal — Brazilian federal universities (periódicos.capes.gov.br) CAPES Gateway URL The authenticated CAPES gateway URL provided by your institution’s library. Leave empty to hit doi.org directly (works only from a CAPES-connected network or active browser session).
